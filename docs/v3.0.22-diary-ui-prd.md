## 0. 原始需求复述（逐字保留语义）

> 「分册里有一个点了没有反应的项，我不知道是什么意思。必须要有一个用户身份（若有多个用户身份可以自己选，不同身份的日记内容不互通），然后才能写日记。日记界面要完全贴合所有主题，要做好全部适配，特别是写日记的部分，着重要做好。要把这个输入框弄大，不能只占画面一小块，再是这个背景透明度要正常，和聊天框的透明度一样。美化一下我的日记这个界面。做完之后上传 GitHub。」

> 补充一：「那这个选项也容易让人看得一头雾水，还不如就写当前身份就行。」

> 补充二：「并且这个当前身份，就是你设置中的目前你正在用的身份，然后你要在这个当前身份的右边加个括号，然后把现在用的身份写出来。」

### 主理人已定口径（写进 PRD，不再讨论；以本节为准）

1. **UI 与用户文档彻底不出现让人看不懂的旧分册占位字样**：空状态、提示、使用说明、`GuideView` 均不得以旧占位词描述日记归属，统一用「当前身份」表述。
2. **单一当前身份、跟随设置、不做切换器**：日记页顶部显示 `当前身份（{selfRoleName}）`——「当前身份」右边紧跟**中文全角括号**，括号内为当前自我身份名（例：`当前身份（小雨）`），直接取 `settings.currentSelfRoleId`。**日记页不自己切换身份，不在日记页内另做身份切换器**；用户想换身份请到「设置」中切换当前自我身份，回日记页即随之变化。日记列表与新建日记都固定绑定这个身份。
3. **身份必选与严格隔离**：必须至少有一个自我身份才能写日记，不同身份的日记严格不互通（沿用 v3.0.18 的 `selfRoleId` 门控）。没有任何自我身份时，空状态直接说「请先创建一个身份，再写日记」并提供跳转设置入口，不提旧占位词。
4. **旧日记自动迁移（内部实现细节）**：`selfRoleId` 不在当前自我身份列表里的日记（`selfRoleId='none'` 及身份已删除的孤儿）**自动归到设置里当前的身份**（`settings.currentSelfRoleId`，无效则内存回落第一个 selfRole）。该迁移**不向用户暴露旧占位词**；界面/用户文档如需解释，只说「旧日记已归入当前身份」。
5. **写日记输入框**：大幅放大（占主区域主要高度，不应只是画面一小块），并让背景透明度与聊天输入框一致——聊天输入框用 `var(--input-bg, #f2f3f5)` / `var(--input-fg, #1f2329)`（见 `src/styles/index.css:73-82`），日记输入框应复用同一组设置变量与主题口径，用户自定义输入框外观时同步生效。
6. **全主题适配与美化**：14 套主题下均清晰可读（WCAG AA），全部颜色用主题变量，禁止新增硬编码色值；日记页整体布局、卡片、按钮、留言/摘要区都要美化，风格与主界面一致；新增/改动动画受三档动画开关控制并登记分组（如需新增）。
7. **收尾铁律**：i18n 10 处（`translations.ts` zh/en + 8 locale JSON）键集合一致、无空值、占位符一致；删除/不再引用 `diary.bookNone` 等旧键，新增带 `{name}` 占位符的「当前身份」语义键；设置索引与搜索候选 ≤5；小窗机制同步（日记页本身在小窗无入口，但身份/迁移逻辑不能破坏小窗）；冻结区 `MiniChat.tsx`/`ChatWindow.tsx`/`cursorCoverState.ts` 零改动；文档同步 `使用说明.md` 与 `GuideView.tsx`、`README.md`、`硬编码清单.md`、`版本更新记录.md`；版本 bump 3.0.22 并上传 GitHub 打 tag。

## 2. 产品定义

### 2.1 Product Goals（3 个正交目标）

1. **单一当前身份，所见即所得**：日记页顶部固定显示 `当前身份（{name}）`，直接跟随设置里的当前自我身份，无分册列表、无日记页内切换器、无看不懂的占位词——用户一眼就知道正在写谁的日记。
2. **身份隔离不串册不丢数据**：日记严格按 `selfRoleId` 隔离；不在身份列表里的日记自动归入当前身份，正文、AI 留言、AI 摘要全部保留且门控自洽，迁移幂等。
3. **写作体验与主界面一致**：写日记输入框放大到主区域主要高度，背景/文字透明度与聊天输入框完全同口径（用户自定义输入框外观同步生效），14 套主题下均达 WCAG AA 且风格统一。

### 2.2 User Stories（5 个场景）

1. 作为**刚打开日记页、还没有自我身份的用户**，我希望看到「请先创建一个身份，再写日记」和能点的跳转入口，这样我清楚下一步该做什么。
2. 作为**想用另一个身份写日记的用户**，我希望到「设置」里切换当前自我身份后，回日记页顶部的名字和日记列表就跟着变——日记页本身不需要提供切换器。
3. 作为**从旧版本升级的老用户**，我希望过去的日记自动归入我现在用的身份、内容和留言摘要都不丢，界面上也不要再出现让我看不懂的占位词。
4. 作为**调整过聊天输入框外观的用户**，我希望日记输入框的透明度、背景和文字色跟着聊天框一起变，这样两个输入区域看起来是一套设计。
5. 作为**使用深色/浅色等不同主题的用户**，我希望写日记和浏览日记时文字都清晰可读、风格与聊天主界面协调，这样任何主题下都能舒服地记录。

## 6. 旧日记迁移矩阵（P0-3）

> 迁移目标 = `settings.currentSelfRoleId`（须在 `selfRoles` 中有效），无效/空则**只在内存回落第一个 selfRole、不回写设置**（已定 Q5）；无身份时不迁移、数据保留隐藏。
> 迁移范围 = 所有 `selfRoleId` 不在当前 `selfRoles` 列表里的日记（含 `none` 与身份已删除的孤儿，已定 Q2）。
> 迁移为**内部实现细节**，不向用户暴露旧占位词；界面/用户文档如需说明，只说「旧日记已归入当前身份」。

| 场景 | 自我身份数 | currentSelfRoleId | 待迁移日记（不在身份列表里） | 日记页表现 | 日记去向 |
|---|---|---|---|---|---|
| A | 0 | — | 0 | 引导空状态（§5.1） | 无 |
| B | 0 | — | >0 | 引导空状态 | 数据保留但隐藏；**创建首个身份后自动归入该身份** |
| C | 1 | 有效 | 0 | 顶部 `当前身份（X）`，单一册 | 无 |
| D | 1 | 有效 | >0 | 顶部 `当前身份（X）`，单一册 | 自动归入该唯一身份 |
| E | ≥2 | 有效 | >0 | 顶部 `当前身份（X）`（= 设置里的身份） | 自动归入 `currentSelfRoleId`；日记页不切换，换身份须去设置 |
| F | ≥1 | 无效/空 | >0 | 顶部 `当前身份（内存中第一个 X）` | 自动归入内存回落的第一个 selfRole；**不回写设置** |

**迁移硬保证（已定 Q1 / Q2）：**

1. **范围与幂等**：以 `selfRoleId` 不在当前 `selfRoles` 列表里为迁移条件；迁移后命中列表、不再重复；重启/重复进入不产生重复数据。
2. **不 revoke、不改游标**：用专用迁移函数，只改日记与摘要的 `selfRoleId`；**不改 `updated_at`、不 revoke 任何留言/摘要**。
3. **门控继续命中**：同步改写 `diary_summaries.selfRoleId`，使 `collectArtifactsForRole` 的 `s.selfRoleId === input.selfRoleId` 与 `s.sourceUpdatedAt === d.updated_at` 继续成立；摘要不失效。
4. **正文/留言/摘要全保留**：`content`、`date`、`title`、`allowAi`、`visibleRoleIds`、`aiComments`、`diary_summaries` 全部保留。
5. **门控自洽**：迁移后该日记在当前身份可见、在其它身份不可见；AI 注入仍只由已产生且仍可见的产物承载，正文永不注入对话（保持 v3.0.18 不变量）。

## 8. 主理人已定结论（交架构师直接执行）

> 以下 6 条为 team-lead 已裁定的最终结论，**不再讨论**；已回灌至 §3 / §4 / §5 / §6 / §7。

1. **迁移函数（原 Q1，已定）**：写**专用不 revoke 的迁移函数**。迁移只改日记与摘要的 `selfRoleId`，**不改 `updated_at`、不 revoke 留言/摘要**，并同步改写 `diary_summaries.selfRoleId` 使 `collectArtifactsForRole` 继续命中；正文、留言、摘要全部保留。
2. **迁移范围与回收入口（原 Q2，已定）**：移除手动孤儿回收入口；数据层迁移范围扩大到「`selfRoleId` 不在当前 `selfRoles` 列表里的所有日记」（含 `none` 与身份已删除的孤儿），自动归到当前默认身份，UI 不再暴露。
3. **跳转目标（原 Q3，已定）**：空状态「去创建身份」按钮跳到**设置页对应身份分区并高亮**，复用现有设置锚点/导航，不用原生弹窗。
4. **大输入框布局（原 Q4，已定）**：正文 textarea 用 `flex:1` + `min-height: 320px`（小屏可滚动），编辑态**内联展开在主区域**，不做覆盖抽屉；与聊天框同口径。
5. **`currentSelfRoleId` 无效（原 Q5，已定）**：只在内存回落第一个 selfRole，**不回写设置**，不影响 `chatSelfRoles` 按会话覆盖。
6. **i18n 旧键（原 Q6，已定）**：`diary.bookNone` / `diary.orphanHint` / `diary.reassignOrphans` 不再使用时**从 10 处彻底删除**，不留空值占位（非置空字符串）。
